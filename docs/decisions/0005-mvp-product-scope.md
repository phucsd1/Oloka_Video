# ADR 0005: Closed-beta prompt-to-video MVP scope

- Status: Accepted
- Date: 2026-08-05

## Context

Phase 0 found broad but overlapping product surfaces. MVP needs one testable value path without distribution, scraping, advanced DAM, or multiple deployment contracts.

## Decision

Ship a closed-beta flow from Google login and admin approval through Project, private Asset, durable generation, structured preview/edit, Modal render, technical verification, playback and download. `MVP_SCOPE.md` and `OUT_OF_SCOPE.md` are normative.

## Consequences

The product ends at download. Social, URL ingestion, advanced Asset intelligence, full visual Studio, collaboration and alternate topology require later product decisions/ADRs.

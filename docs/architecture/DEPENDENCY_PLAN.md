## Dependency rules

- No dependency is added merely to mirror AutoCode Video.
- Prefer official, narrow, ESM/Node 22-compatible packages; document why custom policy remains around any library.
- Production and test adapters have distinct composition roots; no fake/mock package enters production selection.
- Lockfile changes occur only in the approved Phase 3 slice and must pass license/security review plus all validation.
- Renovation is deliberate: patch/minor updates still run contract, migration, security, preview parity, and build tests.
- Provider SDKs are evaluated only when their provider slice is approved. HTTP-standard adapters are preferred where they keep protocol ownership explicit.
- Slice 3A replaces the current floating `node:22-bookworm-slim` and Actions
  `node-version: 22` declarations with the same reviewed 22.16.0 patch. A digest
  may be added only after architecture/build compatibility review. Phase 2.1
  documents this gate and does not edit Docker or workflow files.

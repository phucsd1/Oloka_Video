## MVP cut đề xuất

MVP chỉ gồm: Google auth/approval, canonical Project, private Asset upload, tìm asset theo original filename/media type/upload time/project và optional ingestion status, prompt composer, durable Forge job, one LLM, Omnivoice, HyperFrames contract, preview, Modal render, technical quality gates, immutable output/download và admin user/job/provider health. Workspace vẫn `UNDECIDED`; MVP không được giả lập workspace bằng alias hoặc special project. Mọi UI chưa có backend thật, `posted`/social, scraping, Cloudflare alternate, full visual Studio, semantic/embedding/similar search, AI enrichment, exact/semantic duplicate cleanup, OCR/transcript search, advanced taxonomy và smart BGM để sau.

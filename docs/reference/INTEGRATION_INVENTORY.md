## Nguồn media web bổ trợ

Ngoài 16 boundary trên, pipeline còn có hành vi capture URL, tải media và tìm ảnh qua website/DuckDuckGo/Unsplash. Đây là capability phụ nằm trong prompt asset service, không nên coi là storage provider. Các request có timeout ngắn khoảng 3–15 giây nhưng phụ thuộc mạnh vào CORS, anti-bot, redirects, content type và bản quyền nguồn.

Bằng chứng: `services/promptAssetService.js`, `services/urlDetection.js`, `routes/generate.js`.

Đề xuất: tắt trong MVP mặc định; chỉ bật qua một media ingestion service có allowlist, attribution/licensing metadata, size limit và SSRF protection.

## Nhận xét cross-integration

1. **Cấu hình phân tán:** env, SQLite shared settings và localStorage cùng quyết định provider. Bằng chứng: `services/sharedConfig.js`, `public/app.js`, `Dockerfile`.
2. **Retry không thống nhất:** TTS và Modal có policy rõ, LLM/recognition/social/OAuth không dùng một client chung. Bằng chứng: `services/omnivoiceSceneTts.js`, `services/renderProviders.js`, `services/llmStreamingService.js`, `routes/socialPublish.js`.
3. **Secret boundary yếu:** hosted che secret khi trả response nhưng vẫn lưu plaintext; local browser giữ key. Bằng chứng: `services/sharedConfig.js`, `public/app.js`.
4. **Version coupling:** HyperFrames version phải tương thích giữa Node app, registry và Modal image. Bằng chứng: `package.json`, `deploy/modal-renderer/app.py`, `Dockerfile`.
5. **Không có durable integration job:** social publish và một số analysis chạy trực tiếp trong HTTP request hoặc background RAM. Bằng chứng: `routes/socialPublish.js`, `services/assetAnalysisService.js`.

## Integration tối thiểu đề xuất cho Oloka MVP

- HyperFrames CLI/registry với version pin và preflight.
- Một OpenAI-compatible LLM provider qua adapter có schema validation/idempotency.
- Omnivoice hoặc một TTS adapter duy nhất có alignment.
- Một hosted render provider (Modal hiện tại có thể là implementation đầu tiên sau interface).
- HF Space + durable object storage cho môi trường hiện tại.
- Google OAuth nếu sản phẩm vẫn đóng quyền truy cập.

Recognition nâng cao, web scraping, GitHub OAuth, social publishing và Cloudflare alternate topology nên để hậu MVP.
